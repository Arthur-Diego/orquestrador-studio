Etapa 4 · aula 010

Storyboard

A imagem base vira história. Use a base para ter ideias na interface da Higgsfield — desenhe por cima (Draw to Edit), edite uma instrução por vez, peça outro ângulo (Multi Shot) — importe o que gostou e escreva a história em ~5 cenas, com começo, descoberta, ação e desfecho. Escreva as instruções em inglês (aula 007).

1. Ideias a partir da imagem base

base: ? 0 ideias · 0 escolhidas

O Studio monta a instrução; quem gera é você, na interface da Higgsfield (lá o plano é ilimitado). O upscale das ideias acontece na etapa 5 (aula 011), depois de escolher os ângulos.

Sem base/base_final.png: conclua a etapa 3 para liberar as instruções. Importar ideias e escrever cenas continua funcionando.

Instrução (inglês)

Estes botões não gastam crédito: eles montam o texto para você colar na Higgsfield. Gerar de verdade é lá (ou pelo CLI, abaixo, que gasta créditos).

Cole isto na Higgsfield

CLI: ? origem: imagem base

Draw to Edit só existe na interface (o desenho é seu). No CLI, a aula encadeia as edições: escolha "usar como origem" em uma ideia da galeria para a próxima edição partir dela, e não da imagem base.

2. Importar as ideias que você gerou

precisa de login no CLI

A instrução em uso é gravada junto com cada ideia importada (rastreabilidade). Aceite as imperfeições da IA: corrija com a próxima edição e avance (aula 010).

3. Escolher as ideias do storyboard

Um clique escolhe a ideia; o botão usar como origem faz a próxima geração pelo CLI partir dela (edições encadeadas, aula 010). As escolhidas são copiadas para storyboard/ideas/ e ficam disponíveis para anexar às cenas. Duplo clique abre a imagem.

4. A história em cenas

abrir storyboard.md

A aula 010 escreve ~5 cenas em texto e organiza a linha narrativa em começo → descoberta → ação → desfecho — o rótulo de cada cena abaixo mostra o momento que ela ocupa. Salvar grava storyboard/scenes.json e regrava storyboard/storyboard.md.
