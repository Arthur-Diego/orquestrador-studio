Cole isto na Higgsfield

O que a aula 010 manda fazer aqui

O Studio monta a instrução; quem gera é você, na interface da Higgsfield (lá o plano é ilimitado). O upscale das ideias acontece na etapa 5 (aula 011), depois de escolher os ângulos.

Estes botões não gastam crédito: eles montam o texto para você colar na Higgsfield. Gerar de verdade é lá (ou pelo CLI, abaixo, que gasta créditos). Escreva as instruções em inglês (aula 007).

Draw to Edit só existe na interface (o desenho é seu). No CLI, a aula encadeia as edições: escolha "usar como origem" em uma ideia da galeria para a próxima edição partir dela, e não da imagem base.

A instrução em uso é gravada junto com cada ideia importada (rastreabilidade). Aceite as imperfeições da IA: corrija com a próxima edição e avance (aula 010).

03Escolher as ideias do storyboard

Um clique escolhe a ideia; o botão usar como origem faz a próxima geração pelo CLI partir dela (edições encadeadas, aula 010). As escolhidas são copiadas para storyboard/ideas/ e ficam disponíveis para anexar às cenas. Duplo clique abre a imagem.
