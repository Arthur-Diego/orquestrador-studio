# Exemplo: Matrix Core tecnológico

Este exemplo demonstra a forma da resposta. Ele não substitui a inspeção da imagem real.

## Resumo executivo

A imagem combina fotografia cinematográfica low-key, verde fosforescente e materiais pretos brilhantes. A leitura mais forte é **Matrix Core / Tech Noir**, com sinais de tecnologia do fim dos anos 1990 e início dos 2000. O moodboard deve ampliar esse universo por arquitetura, CRT, textura digital, tipografia monoespaçada e traduções 2D/3D.

## DNA visual

| Dimensão | Leitura | Tipo | Confiança |
| --- | --- | --- | --- |
| Modalidade | fotografia cinematográfica realista | observado | alta |
| Cor | preto dominante e verde fosforescente | observado | alta |
| Luz | low-key, lateral, alto contraste | observado | alta |
| Materiais | couro, vidro e metal escuro | observado/inferido | média |
| Época | late 90s / Y2K tecnológico | inferido | média |
| Emoção | misteriosa, controlada, tensa | inferido | média |

## Vibes

- Principal: `Matrix Core / Tech Noir` — confiança alta.
- Relacionadas: `Hacker Core`, `Digital Dystopia`, `Y2K Tech`, `Cyberpunk Minimal`.

## Incertezas

- A paleta é aproximada sem amostragem de pixels.
- A época é uma inferência estética, não uma data confirmada.
