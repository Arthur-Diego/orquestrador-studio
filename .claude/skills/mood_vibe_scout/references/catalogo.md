# Catálogo de vibes

Duas listas: **as 30 do catálogo** (numeradas, prefixo vazio no arquivo) e o **banco de
sugestões** (vibes fora do catálogo que a skill pode propor — viram `extra-` no arquivo).

Vibe pedida pela pessoa que **já existe** no catálogo entra como `catalogo` com o número dela
(não vira `custom-`): o prefixo marca vibe fora do catálogo, não "quem falou primeiro".
Vibe pedida pela pessoa que **não existe** no catálogo entra como `usuario` → `custom-`.

⚡ = pegada tecnológica / Matrix / digital.

### Notas de coleta já conhecidas

- `clay-3d`: a busca ingênua `clay 3d art` traz **fotos de cerâmica real**. A query do catálogo
  já está corrigida — não voltar para a antiga.
- `futuristic-minimal`: `futuristic minimal aesthetic` tende a devolver pôster tipográfico.
  Se a pessoa quer **ambiente/cena**, trocar por `futuristic minimal interior`.

## Banco de sugestões (fora do catálogo → `extra-`)

Use para propor 2–4 vibes que o catálogo não cobre, escolhidas pelo que a entrevista revelou.
Nunca despejar a lista inteira: proponha só o que conversa com a resposta da pessoa.
